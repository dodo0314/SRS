# SRS

마크다운으로 쓴 카드를 간격 반복(FSRS)으로 복습하는 웹앱. 아이폰 홈 화면에 설치해 쓴다.

빌드 과정이 없다. 브라우저가 그대로 읽는 ES 모듈이라 이 저장소가 곧 배포본이다.

## 이 저장소에 없는 것

**카드 내용과 학습 기록은 여기 없다.** 앱은 실행할 때 사용자가 지정한 별도의 비공개 저장소에서 카드를 읽고, 복습 기록도 그쪽에 쓴다. 접근에 쓰는 토큰은 사용자 기기의 브라우저에만 저장되며 이 코드에는 들어 있지 않다.

즉 이 주소를 아무나 열어도 자기 저장소와 토큰이 없으면 빈 설정 화면만 보인다.

## 기능

- FSRS 스케줄러 — 카드별 안정성·난이도 추적, 목표 유지율 조절
- 카드 4유형 — 기본 / 역방향 / 빈칸 / 논점 나열
- 근거 필드 — 카드에서 원문 조문 파일로 바로 이동, 근거 없는 카드 경고
- 오프라인 복습, 온라인 복귀 시 자동 저장
- 덱·태그 필터, 복습 예보와 통계

## 설치

앱 소스와 문서는 카드가 있는 저장소에서 관리한다. 설치 절차, 카드 형식, 테스트는 그쪽 `srs/` 폴더를 참조한다.

1. 이 저장소에서 Settings → Pages → Deploy from a branch → `main` / `/ (root)`
2. 발급한 주소를 사파리로 열고 공유 → 홈 화면에 추가
3. 앱에서 저장소와 토큰 입력
